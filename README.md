# Sistemas de Información EAFIT · Grupo 1

Material inicial para trabajar en la Entrega 3.

## Archivos

- `index.html`: mockup interactivo de la Entrega 2. Incluye catálogo de centros, eventos simulados, estados, historial y criticidad ilustrativa.
- `PlantillaEntrega03_2026-2.docx`: plantilla del profesor para la entrega final.

## Abrir el mockup

Descarga `index.html` y ábrelo en un navegador moderno. No requiere instalar dependencias. La vista de código de GitHub no ejecuta el HTML.

El mockup usa datos ficticios. Los cambios se conservan solo durante la sesión y se reinician al recargar. No hay servidor, base de datos, conexión con dispositivos, integración con Aranda ni notificaciones reales. Este repositorio inicial no acredita un despliegue funcional de Entrega 3.

## Trabajo del equipo

Usar la plantilla para acordar alcance, criterios de aceptación y responsabilidades; documentar el desarrollo, las pruebas y el despliegue que realmente se realicen. Registrar las contribuciones con sus autores reales.
